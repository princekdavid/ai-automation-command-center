# Roadmap

## Phase 0 — Foundation
- Product vision
- PRD
- Architecture
- Governance rules
- Status tracking
- Security model

## Phase 1 — MVP
- Project connection
- Framework discovery
- Framework DNA
- Capability detection
- Test discovery
- Test Explorer
- Framework-native execution
- Live execution
- Results/evidence
- Failure analysis
- Skill gap detection

## Phase 2 — Intelligence
- AI test design
- AI-assisted automation generation
- Intelligent prioritization
- Test-data assistance
- Flaky-test intelligence
- Deeper root-cause analysis

## Phase 3 — Advanced Automation
- Skill generation and lifecycle
- Self-healing
- Framework optimization
- Custom adapters
- Multi-project
- CI/CD control
- Enterprise integrations

## Delivery Principle
Build the control plane first. Add autonomy only after discovery, execution, observability and validation are reliable.
